Agent tools

The agent receives OpenAI-compatible function tools mapped to these chat actions:

  • chat.checkCheck messages by time range and number.
  • chat.searchSearch for specific words or phrases.
  • chat.reactAdd emoji reactions to messages.
  • chat.reactionsCheck emoji reactions on messages.
  • chat.sendSend an agent message into the chat.
